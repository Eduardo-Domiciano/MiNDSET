# Essa anotação tem o intuito de ajudar a criar arquivos shell de automatização e transforma-las em comandos.

### Crie uma automação:
- 1. Crie um script shell no formato `.sh`:

- 2. Para tonar executavel, use o comando `sudo chmod +x <nome-do-arquivo.sh>`.

- 3. teste e edite o arquivo até chegar no objetivo desejado.

### Transformando em comando:

- 4. Quando a automação estiver pronta, mova para a pasta `~/bin`.

- 5. Remova a extenção `.sh` do arquivo, deixando apenas o nome.

- 6. Agora use o comando novamente para torna-lo executavel, mas desta vez usando apenas o nome do arquivo, sem a extenção `chmod +x <nome-do_arquivo>`
