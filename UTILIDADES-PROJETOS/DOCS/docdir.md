# DOCS

Modelos de documento para abrir e acompanhar um projeto.

## Arquivos

| Arquivo | O que faz |
| --- | --- |
| `MODELO-PRD.md` | Modelo de PRD: o que o projeto entrega, para quem, e como saber que ficou pronto. |
| `MODELO-DRT.md` | Modelo de DRT: como o sistema é construído para cumprir o PRD. |

## Observacoes

- Copie o modelo para o projeto e preencha. O arquivo desta pasta permanece em branco.
- O DRT aponta para o PRD. Requisito de negócio novo entra primeiro no PRD.
