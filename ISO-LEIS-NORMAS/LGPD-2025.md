# Anotações sobre o estudo da Lei Geral de Proteção de Dados LGPD.

A Lei Geral de Proteção de Dados Pessoais (LGPD), Lei nº 13;709/2018, é a legislação brasileira que regula as atividades de tratamento de dados pessoais. Inspirado na GDPR (General Data Protection Regulation) europeia, a LGPD estabelece regras claras sobre coleta, armazenamento, tratamento e compartilhamento de dados pessoais, tanto no ambiente digital quanto fisico.

## Direitos dos titulares

- Acesso aos dados.
- Correção de dados incompletos, inexatos ou desatualizados.
- Anonimização, bloqueio ou eliminação de dados desnecessário ou tratados em desconformidade.
- Portabilidade dos dados.
- Revogação do consentimento.

## Obrigações das Empresas:

As empresas devem estar adequadas as normas da LGPD:
- Mapear os processos de tratamento de dados.
- Garantir que há uma base legal para cada tratamento.
- Adotar medidas de segurança para proteger os dados.
- Indicar um encarregado de proteção de dados (DPO).
- Elaborar relatórios de impacto a proteção de dados pessoais (RIPD) quando o tratamento apresentar alto risco.

A fiscalização e aplicação de sanções sao de responsabilidade de Autoridade Nacional de Proteção de Dados (ANPD).
