# SiNTAXE_JS

## Arquivos

| Arquivo | O que faz |
| --- | --- |
| `java_script.md` | Sintaxe básica da linguagem, com explicação e exemplo em cada tópico. |
| `condicionais.js` | Rascunho de `if`, `switch` e operador ternário. |
| `funcao.js` | Rascunho dos formatos de função. |
| `loop_repeticao.js` | Rascunho de `for`, `while` e `do-while`. |
| `calcula-media.js` | Script de terminal que lê números e calcula a média. |
